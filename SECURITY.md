# Security Policy

This repository packages an ARC-Bench / Factory26 adapter and pinned runtime components. Please do not disclose security-sensitive findings in a public issue before they are triaged.

## Reporting

Use GitHub Private Vulnerability Reporting / Security Advisories for this repository when available:

https://github.com/putao520/arc-claude-gsc/security/advisories/new

Include the affected commit or submission build, reproduction steps, impact, and whether the finding is in this adapter/package logic or an upstream bundled component.

For vulnerabilities that are clearly in an upstream third-party component, also report them to the upstream project through its security process. Please still tell us privately when the pinned/bundled version in this repository is affected so the packaged runtime can be updated.

Ordinary build failures, benchmark behavior, compatibility issues, and feature requests should use public GitHub Issues.
